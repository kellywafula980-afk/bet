# Betting Site with Paystack

## Setup
1. Create virtual environment and install requirements.
2. Run migrations.
3. Set up .env with Paystack keys.
4. Run server.

## Features
- User registration/login
- Wallet with deposits via Paystack
- Place bets on matches (1X2 market)
- Automatic odds updating (placeholder)
- Admin panel for match management
